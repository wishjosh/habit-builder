# 습관 형성 시스템 · Habit Builder

우리 가족의 작은 실천을 모으는 아이패드용 웹앱입니다.

**앱:** https://wishjosh.github.io/habit-builder/

현재 버전은 **0.14.0**입니다. 최초 버전부터의 실제 배포 번호와 정리한 번호의 대응 관계, 앞으로 번호를 올리는 기준은 [버전 기록](CHANGELOG.md)에 있습니다. 과거 Git 커밋과 당시 배포 파일은 변경하지 않았습니다.

## 시작하기

1. Safari에서 앱을 열고 첫째 또는 둘째를 고릅니다. **설정 → 함께하는 아이들 → 바꾸기**에서 아이별로 쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지 중 캐릭터를 고를 수 있습니다. 기존 캐릭터는 새로 선택하기 전까지 유지됩니다.
2. 아이가 **이번 주 할 일**에서 묶음별 요일을 먼저 정할 수도 있고, **오늘 할 일**에서 할 일을 만들면서 그 일의 반복 요일을 바로 고를 수도 있습니다. 주간 묶음에 정한 날에는 세부 할 일이 없어도 묶음 이름으로 실천할 수 있습니다. 그날 세부 할 일을 정했다면 묶음 이름 대신 그 항목을 완료합니다.
3. **오늘 → 오늘 / 내일 미리 정하기 → 할 일 추가**에서 묶음을 고르거나, 일기처럼 **묶음 없이** 할 일을 적습니다. 작성 중 새 묶음도 만들 수 있습니다. 책·교재 이름과 분량을 채운 뒤 **이날만 / 반복하기**를 고릅니다. 반복하기에서는 **매일**, **요일 고르기**, **하루 걸러 격일** 중 하나를 선택하고, **시작하는 주만 / 날짜까지 / 종료일 없이 계속**을 정합니다. 내일의 한 번 하는 계획은 이번 주 남은 예정일 중 원하는 날에 복사할 수도 있습니다. 실천한 뒤 **다 했어요**를 누르면 끝입니다. 평가나 소감 입력은 요구하지 않습니다.
4. 내 기록에서 주간·월간·활동별 기록을 봅니다. **별 모으기**에서 모은 별과 가족이 함께 고를 수 있는 목록을 봅니다. 월간 기록은 인쇄하거나 PDF로 저장할 수 있습니다.
5. Safari의 공유 → **홈 화면에 추가**를 누르면 앱처럼 열 수 있습니다. 기록을 만든 Safari 창과 홈 화면 앱 사이의 저장 공유는 iPadOS 환경에 따라 달라질 수 있으므로 가족 연결을 각각 확인합니다.

**이번 주 할 일**에서는 묶음에 할 요일을 미리 정할 수 있습니다. 세부 할 일에서 직접 반복 요일이나 격일을 정했다면 해당 날짜와 항목도 같은 화면에 나타납니다. 묶음 일정과 세부 할 일 반복 일정은 서로 독립적이므로 한 묶음의 눈높이는 매일, ORT는 하루 걸러 정할 수 있습니다. 격일은 시작일부터 이틀마다 이어져 주가 바뀌어도 순서를 유지합니다. **다음 주** 버튼을 누르면 일요일에도 다음 주 계획을 볼 수 있습니다. 묶음의 다음 주 일정을 바꾸거나 지워도 이번 주 일정과 완료 기록은 유지됩니다. 새 세부 계획은 각각 완료할 때 별 1개이며 중복 적립되지 않습니다. 내일 계획은 오늘 완료할 수 없습니다. 완료 버튼을 다시 누르면 실수로 한 표시를 취소할 수 있습니다.

반복 할 일의 책 제목이나 분량이 바뀌면 그 날짜의 카드를 열고 **함께 바꾸기**를 누릅니다. **이날만**은 그날의 할 일만 바꾸고, **이날부터**는 앞으로 나타나는 할 일의 기본 내용을 바꿉니다. 반복 요일·종료 날짜도 ‘이날부터’를 고른 뒤 바꿀 수 있습니다. ‘날짜까지’는 고른 날짜를 포함해 반복하고 다음 날부터 나타나지 않습니다. ‘종료일 없이 계속’은 부모와 함께 그만할 때까지 이어지지만, 먼 미래의 할 일을 한꺼번에 저장하지는 않습니다. 이미 완료한 날짜의 제목·분량과 별은 당시 기록으로 남습니다. 변경에는 부모 공동 확인이 필요합니다.

반복 할 일 카드의 **삭제**를 누르면 **이날만 빼기 / 이날부터 그만하기**를 고릅니다. 이날만 빼면 미실행으로 세지 않고 다른 날은 계속 나타납니다. **할 일 관리**에서 뺀 날짜를 찾아 **다시 넣기**를 누를 수 있습니다. 이날부터 그만하면 이전 실천과 별은 남습니다. 완료한 날을 계획에서 빼려면 먼저 그날의 완료를 취소해야 합니다. 잘못 만든 시험용 할 일을 실천 기록과 별까지 완전히 지우려면 **할 일 관리 → 지난 할 일 → 정리**를 사용합니다. 기존 반복 할 일은 종료일 없이 계속되거나 시작하는 주에 끝나는 기존 설정을 그대로 유지합니다.

내일의 세부 계획을 만들 때 ‘이번 주 다른 날에도 넣기’를 선택하면 주간 일정에 맞는 남은 날이 표시됩니다. 이 중 복사할 날을 각각 골라 책·교재 이름과 할 일·분량을 넣습니다. 예를 들어 영어 묶음은 매일로 두고 눈높이 영어는 남은 날 모두, ORT는 격일에 해당하는 날만 고를 수 있습니다. 같은 날 한 묶음에 여러 할 일을 둘 수 있어 눈높이 수학과 기탄 수학을 함께 계획할 수 있습니다. 이미 책·교재 이름과 할 일 내용까지 같은 계획이 있는 날만 중복을 막습니다. **이번 주 할 일**의 묶음 카드에는 해당 주에 정한 세부 할 일이 날짜별로 보입니다. 항목을 누르면 그 날짜의 **오늘 할 일**로 이동하고, 아직 완료하지 않은 오늘 이후의 계획은 부모와 함께 바꿀 수 있습니다. 복사한 계획은 할 일 관리에서도 날짜별로 확인하고 정리할 수 있습니다. 책의 챕터나 분량이 매일 다르면 복사 옵션을 끄고, 최근 할 일 버튼으로 책 제목을 다시 불러와 그날 분량만 바꿔 적습니다. 복사한 계획은 실제로 완료할 때만 별을 받습니다.

처음 정하는 일정과 세부 계획은 아이가 직접 저장합니다. **이번 주 할 일**의 묶음 카드에서 반복 일정을 그만하고, **오늘 할 일**의 세부 카드에서 날짜별 계획을 정리할 수 있습니다. 종료된 일정은 ‘정하기’로 표시합니다. 그 묶음에 날짜별 할 일이나 완료 기록이 전혀 없다면 ‘정하기’를 누를 때 오래된 종료 일정만 정리합니다. 이미 정한 일정·세부 계획의 변경·정리에는 **부모님과 함께 확인했어요** 표시가 필요합니다. 확인은 가족이 함께 쓰는 절차이며 부모 신원을 인증하는 PIN 잠금은 아닙니다. 별도 승인 요청함이나 의무적인 이유 입력은 없습니다. 계획을 바꿔도 지난 실천 기록은 유지됩니다. 완료한 세부 계획도 **할 일 관리**에서 앞으로 그만하거나 기록에서 완전히 지울 수 있습니다.

이번 주 할 일의 요일을 바꾸거나 일정을 그만해도 이미 작성한 날짜별 세부 계획은 남깁니다. 필요하면 해당 날짜에서 부모와 함께 삭제합니다. 쉬는 날에는 새 실천 버튼이 잠기고 기존 기록은 남습니다. 선물 사용 후 과거 실천을 취소하면 별 잔액이 음수가 될 수 있습니다. 설정에서 선물 사용을 취소하면 돌려받습니다.

새로 정한 오늘·내일 할 일은 완료할 때 별 1개를 받습니다. 이전 방식의 할 일에는 항목별 별 개수가 남아 있을 수 있습니다. **설정 → 우리 가족의 선물**에서 목록 항목을 수정·삭제할 수 있습니다. 삭제해도 이미 교환한 내역과 사용한 별은 그대로 남습니다.

## 상위 묶음과 구체적인 할 일

오늘 화면은 **책 읽기 / 수학 / 기타 학습 / 생활 습관 / 몸 움직이기 / 만들고 표현하기** 등의 묶음을 접고 펼칠 수 있습니다. 묶음이 필요 없는 할 일은 바로 표시합니다. 주간 묶음에 정한 날에는 세부 할 일이 없으면 묶음 이름으로 완료하고 별 1개를 받습니다. 같은 날 세부 할 일을 정했다면 묶음 대신 각 세부 할 일에 완료 버튼이 나타납니다. 이미 묶음 이름으로 완료한 날에는 완료를 취소한 뒤 세부 할 일을 추가할 수 있습니다.

**설정 → 상위 묶음 관리**에서 원하는 묶음을 추가하고 이름·모양·입력 방식을 바꾸거나 삭제할 수 있습니다. 각 묶음의 **위·아래** 버튼으로 순서를 바꾸면 오늘·이번 주 할 일과 할 일 관리 목록에도 같은 순서가 적용됩니다. 묶음과 순서는 두 아이가 함께 사용하며, 할 일과 완료 기록은 아이별로 분리합니다. 책·교재 제목이 필수인 방식과 이름을 선택적으로 적는 방식을 고를 수 있습니다.

묶음을 삭제할 때 남아 있는 두 아이의 할 일은 선택한 다른 묶음으로 옮깁니다. 완료 기록과 별은 유지되며, 지난 기록에는 삭제한 묶음 이름이 남습니다. 이름만 바꾸면 그 묶음의 기록 화면 이름도 함께 바뀝니다. 묶음은 하나 이상 있어야 하므로 마지막 묶음을 삭제하려면 새 묶음을 먼저 만듭니다. 이전 저장본에는 기본 묶음이 자동으로 보충됩니다.

- 책 읽기 → **톰 소여의 모험** → **1~2장 읽기**
- 수학 → **눈높이 수학** → **A1권 1~2쪽 풀기**

각 묶음의 **할 일 정하기**에서 책·교재 이름과 할 일·분량을 적습니다. 최근에 사용한 책·교재는 다시 선택할 수 있습니다. 생활·운동처럼 제목이 필수가 아닌 묶음은 할 일 하나만 적으면 됩니다. 같은 날 책을 두 권 읽으려면 **하나 더 정하기**로 각각 추가합니다. 다음 날짜의 책과 분량은 아이가 직접 정하며 페이지를 자동으로 넘기거나 미완료 항목을 자동으로 이월하지 않습니다.

완료하면 **내 기록 → 월간 기록 → 이 달에 읽은 책과 한 일**에 제목별로 모입니다. 책 제목을 펼치면 날짜와 분량을 확인할 수 있습니다. 같은 제목을 여러 번 읽은 기록은 한 목록에 모으되 실천 횟수는 따로 셉니다. 읽기 기록을 완독 권수로 계산하지 않습니다. 다른 판본이나 동명의 책을 구분하려면 제목에 출판사 등을 덧붙입니다.

이전 버전의 할 일·반복 설정·기록은 자동으로 바꾸지 않습니다. **설정 → 할 일 목록 관리**에서 ‘현재 할 일’과 ‘지난 할 일’을 전환해 두 아이의 계획을 날짜별·상위 묶음별로 볼 수 있습니다. 지난 할 일에는 구체적으로 정한 날짜별 계획의 완료·미실행·취소와, 그만한 반복 할 일이 표시됩니다. 주간 묶음 일정만 있었던 날은 미실행으로 세지 않습니다. 할 일의 **정리**를 누르면 앞으로만 그만해 실천 기록과 별을 남기거나, 잘못 만든 항목을 해당 실천 기록·별과 함께 앱 기록에서 완전히 지울 수 있습니다. 이미 교환한 선물 내역은 남으므로 별 잔액이 음수가 될 수 있습니다. 가족 연결을 쓴다면 삭제도 동기화되어야 다른 기기에 반영됩니다. 내려받은 백업 파일과 Google 시트의 이전 저장본은 자동으로 바뀌지 않을 수 있습니다. ‘내 기록’의 활동별 발자국에는 실제 실천한 일만 보이며, 월간 날짜 화면에서는 구체적으로 계획하고 지나간 미실행 항목을 확인할 수 있습니다. 처음 사용하는 기기에는 예시 할 일을 자동 생성하지 않습니다. 완료 당시의 책·교재·묶음은 기록에 보존됩니다. 월간 인쇄 시 접힌 세부 기록도 펼쳐 출력하며, 주간 한마디는 **한마디 남기기 (선택)**를 펼칠 때만 보입니다.

## 데이터 저장

화면과 코드는 **GitHub Pages**에서 제공합니다. 가족 기록은 **비공개 Google 스프레드시트**에 저장하며 Apps Script가 읽기·쓰기 통로가 됩니다. Sheets 연결 전에는 이 브라우저에만 저장합니다. 연결 상태는 화면에 표시됩니다. 별도 가족 연결 코드로 각 기기를 연결해야 합니다.

인터넷이 끊겨도 이 기기에 저장하며 다시 연결되면 동기화를 시도합니다. 동시에 여러 기기에서 변경해 충돌하면 자동 덮어쓰기를 중단합니다. 먼저 각 기기의 전체 백업을 받은 뒤, 연결 설정에서 가족 기록을 가져올 수 있습니다. 초기 버전은 두 기기의 충돌 기록을 자동 병합하지 않습니다. 복구 전 로컬 백업을 보관하세요. 브라우저 데이터 삭제·기기 분실에 대비해 전체 기록 백업도 주기적으로 받으세요.

아이 이름·실천 기록·연결 열쇠는 공개 저장소에 포함하지 않습니다. 연결 코드는 기록을 읽고 바꾸는 열쇠이므로 가족만 보관합니다. 설정 화면에는 PIN 보호나 계정별 권한 분리가 아직 없습니다. 일반 백업 파일에는 연결 열쇠가 포함되지 않습니다.

### Google 저장소 만들기

1. 개인 Google 계정의 Apps Script에 새 프로젝트를 만들고 `google/Code.gs`를 붙여넣습니다. 다른 GitHub 계정에서 배포한다면 `APP_ORIGIN`을 해당 Pages 출처로 바꿉니다.
2. `setup`을 한 번 실행하고 Google이 요청하는 스프레드시트 권한을 검토합니다. 비공개 시트가 생성되며 실행 로그에 시트 주소와 가족 열쇠가 표시됩니다. 가족 열쇠를 안전하게 보관합니다. 원문 열쇠는 서버 속성에 저장되지 않으므로 다시 조회할 수 없습니다.
3. 새 배포 → 웹앱 → 실행 사용자 **나**, 액세스 **모든 사용자**로 배포합니다. 웹앱에 접근할 수 있어도 모든 기록 읽기·쓰기는 가족 열쇠 검사를 통과해야 합니다. 시트 자체는 공개하지 않습니다.
4. 앱의 설정 → 가족 기록 연결 → 연결 주소와 열쇠 직접 입력에 `/exec` 주소와 가족 열쇠를 넣습니다.
5. 첫 기기를 연결한 다음 **다른 기기 연결**에서 코드를 받아 아이패드에 입력합니다.

시트의 `State`는 앱이 관리하는 저장 원본, `이전 저장`은 직전 저장본입니다. 직접 수정하지 마세요. `실천 기록`, `아이와 활동`은 보기 편하게 만든 표이며 앱에서 저장할 때 갱신됩니다. 시트 표를 수정해도 앱 계획에는 반영되지 않습니다. 기록 수정은 앱의 설정을 사용하세요.

## 개발 및 확인

별도 설치 없이 Node.js 22 이상에서 `npm start`로 열고 `npm test`, `npm run check`로 검사합니다. 외부 라이브러리, 광고, 추적 도구를 사용하지 않습니다. 서버 파일은 `google/Code.gs`에 있습니다. GitHub Pages 배포는 main 브랜치의 루트 폴더를 사용합니다.

초기 기능은 iPad 화면 크기에 맞춰 확인합니다. 실제 iPad Safari에서의 터치 조작과 Google 연결은 가정 시험 사용에서 함께 확인할 항목입니다.
